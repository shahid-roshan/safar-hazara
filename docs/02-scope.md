# Safar Hazara: Scope

## Must (iske bina project adhoora)
- Signup aur login (Tourist aur Admin)
- Destinations: list aur detail page (description, best season, local tips, kya saath rakhein, transport type)
- Map: destinations ke markers (Leaflet + OpenStreetMap)
- Hotels: list aur detail (price range, services)
- Trip Planner: din-wise stops ki list (simple version)
- Admin: destinations aur hotels add/edit/delete

## Should (waqt mile to)
- Reviews (Admin approval ke baad dikhein)
- Search aur filters (season, budget)
- Budget calculator (transport + stay + khana = total)
- User dashboard (meri trips)

## Could (bonus)
- Favorites
- Hotels ko side-by-side compare karna

## Won't (abhi nahi)
- Online booking aur payments
- Chat
- Mobile app
- Kai zubanon mein website
- AI features (supervisor ke review ke baad)
